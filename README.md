# 📌 Project 1: Smart City Traffic Patterns Forecasting

## Overview

This project predicts hourly traffic volume at city junctions using Machine Learning algorithms. It helps improve traffic management, reduce congestion, and support smart city planning.

## Features

- Data preprocessing
- Feature engineering
- Machine Learning model training
- Random Forest Regression
- Traffic prediction
- Streamlit Web Application

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib

---

# 🌱 Project 2: Crop & Weed Detection using YOLOv8

## Overview

This project detects crops and weeds from agricultural images using the YOLOv8 object detection model. It supports precision agriculture by enabling automated weed identification.

## Features

- Image preprocessing
- YOLOv8 object detection
- Model training
- Real-time prediction
- Streamlit Web Application

## Technologies Used

- Python
- YOLOv8 (Ultralytics)
- PyTorch
- OpenCV
- Streamlit
